## Definition of Ready

- [ ] O responsável autorizou implementar M0-01 (não só preparar documentos).
- [x] Repositório privado criado: `NeuroCapacitar/lms` (organização, GitHub Free). **Não** substituir nem apagar o legado `NeuroCapacitar/hub`.
- [ ] Versões reais de Bun, Node LTS, TypeScript e do plugin Cloudflare confirmadas antes de fixar dependências.
- [ ] Quem tem escrita no repositório e quem publica em Staging definido; Production fica sob controle manual.

## Plano operacional

1. Inspecionar o checkout para não sobrescrever arquivos existentes.
2. Incorporar este conjunto de documentos ao repositório novo, preservando `docs/`, `AGENTS.md` e as pontes de agentes.
3. Fixar versões compatíveis de Bun, Node LTS, TypeScript, Vite, Cloudflare Vite Plugin e das ferramentas do M0.
4. Criar `package.json`, `bun.lock` e scripts mínimos **somente ao implementar**; documentar só comandos realmente executados.
5. Criar CI seguro (duas camadas, sem segredos de Production) e a verificação de ausência de segredos (Gitleaks CLI).
6. Validar um clone limpo: lockfile congelado, checks disponíveis e documentação.
7. Registrar evidências em `STATUS.md`; concluir M0-01 antes de qualquer outra tarefa.

## Não fazer

- Não implantar domínio nem tocar o DNS do legado; não executar migrations de Production nem criar dados reais.
- Não implementar Auth, Course, Asaas, certificados, PWA ou outros marcos.
- Não copiar `package.json`, `.env` ou scripts do legado.
- Não contratar serviços nem assumir custo recorrente (teto: US$ 10/mês).

## Critérios de aceite

- [ ] Repositório vNext independente, privado e com acesso restrito.
- [ ] Instruções de IA e documentação canônica presentes e navegáveis.
- [ ] Versões travadas, `bun.lock` e scripts documentados.
- [ ] `.gitignore` impede segredos e arquivos locais.
- [ ] Instalação e verificações mínimas executadas com êxito num checkout limpo.
- [ ] CI do M0-01 verifica qualidade básica sem segredos de Production.
- [ ] Resultados, limitações e SHA documentados; próximos passos não executados.

**Importante:** o kit não contém `package.json` nem `bun.lock`. Não marque os critérios como cumpridos pela existência deste documento.
